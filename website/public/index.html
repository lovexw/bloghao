五分钟，把博客搬到云上

需要一个免费的 Cloudflare 账号，完事。

  1. 克隆并安装 
    git clone https://github.com/lovexw/bloghao.git
cd bloghao && npm install
npx wrangler login
  2. 创建资源（D1 数据库 + R2 图床） 
    npx wrangler d1 create bloghao-db
npx wrangler r2 bucket create bloghao-images
# 把返回的 database_id 填进 wrangler.jsonc
  3. 初始化数据库并部署 
    npx wrangler d1 execute DB --remote --file schema.sql
npm run deploy
  4. 创建管理员，开写！

    访问 https://bloghao.你的子域.workers.dev/admin/，首次进入即创建管理员账号，欢迎文章已就位。

推上 GitHub 后可开启自动部署（Actions 已内置）→ 完整部署教程
