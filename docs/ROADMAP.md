# 开发方向备忘

记录**已调研、尚未启动**的功能方向。每项保留调研结论与待决策点，启动开发时不必重新摸底；一旦定案实现，具体用法应移入 GUIDE / API / THEMES 等功能文档，本文件只留条目与状态。

2026-10 对标 WordPress / emlog 等系统做过一轮全量能力盘点，方向按三档优先级管理：**A = 一定要做**（下一步就做，多数成本低、确定性强）；**B = 未来一定要做**（重要，但有前置依赖或需先拍板）；**C = 加分项**（可有可无，有富余再做）。下表条目全部处于「未启动」状态；某项启动时，照「会员体系」的格式在本文件展开独立小节并回填状态。

**建议执行顺序**：~~A1–A3（数据主权与功能缺口）→ A7（一键部署）~~（已完成）→ A4 / A6 → A5（插件钩子）→ 进入 B 区。B 区若只先挑三项：B1（邮件服务，解锁下游最多）、B9（主题外观变量，生态破零）、B10（MCP，低成本差异化）。

## 会员体系（游客注册 + 分级会员）

**状态：调研完成，未启动。** 前置条件是「待拍板决策」三项由站长定案。

### 需求设想

游客可注册成为站内会员，分三级：

| 等级 | 设想权益 |
| --- | --- |
| 普通会员 | 日常评论（自动带会员昵称/头像）、发评论攒积分 |
| 咖啡会员 | 可阅读「专属文章」正文，游客与普通会员只见付费墙遮挡 |
| 顶级会员 | 更高权限（具体权益待定义，见待拍板） |

### 调研结论（2026-10，基于当前代码）

**现成可复用的基础：**

- `src/auth.ts`：PBKDF2 密码哈希、Session 签发与 Cookie、`rateLimit` 限流工具，直接复用
- 评论体系已区分 `is_admin` 身份，公开评论接口（`/api/public/comments` 等）已查会话，挂会员身份很顺
- `ensureSchema()`（src/db.ts）有轻量迁移模式，加表加列按此办理
- 设置面板开关模式成熟（参照 `allowComments` 等），会员功能开关照抄

**架构红线：会员不得写入现有 `users` 表。** 该表承载「管理员」语义——`/api/auth/setup` 靠 `countUsers() === 0` 判断首次初始化，`/api/auth/login` 只查这张表；游客注册混入会破坏部署初始化流程。正确做法：

- 单独建 `members` 表（`tier: normal | coffee | top`、`points`、`status` 启用/封禁等字段），独立会话 Cookie（如 `xw_member_session`），与管理员登录互不干扰
- `comments` 表加 `member_id` 列（0 = 游客）挂身份，评论员管理后台可加会员标签
- `posts` 表加可见性列（如 `min_tier`），编辑器加「谁能看」档位选择

**分期建议：**

1. **P1**：注册 / 登录 / 退出 + 会员中心页 + 评论自动带会员身份 + 积分累计（工作量约等于留言板功能）
2. **P2**：文章「会员可见」开关 + 付费墙服务端截断 + 防泄漏清单逐项落实
3. **P3**：后台会员管理页（列表 / 改档位 / 封禁）+ 升级机制（兑换码或积分达标自动升级）

### 待拍板决策（启动前必须定）

1. **升级路径**：Workers 上没有国内支付渠道（微信支付需商户号）。可选项：
   - 赞赏收款码 + 后台手动升级（推荐起步，文章/会员页放码，站长见转账后后台操作）
   - 兑换码：站长生成一批码发放，注册后输码升级
   - 积分达标自动升级咖啡会员（与积分体系天然衔接）
2. **注册门槛**：目前无邮件服务，**邮箱验证与自助找回密码做不了**（只能后台管理员重置；上表 B1 邮件服务落地后可解）。起步为「用户名 + 密码 + 可选邮箱」，防滥用靠蜜罐 + 限流（评论/友链已有同款模式），要更稳可接 Cloudflare Turnstile（免费，Workers 生态原生，即上表 C7）
3. **积分规则与顶级会员权益**：获取/消耗规则（如评论 +2、每日登录 +1）与顶级会员「更高权限」的具体内容不定义清楚，第三级做出来是空壳

### 实现时的防泄漏清单（付费墙旁路）

`renderPost` 为服务端渲染，在服务端截断正文即安全（内容不会下发到浏览器）。但以下旁路必须同步处理：

- `src/rss.ts`：`rssFullText=1` 时完整正文进 `content:encoded`，会员专属文章须剔除或只出摘要
- `/api/public/posts` 接口、搜索页（`listPosts` 的 `content LIKE` 会命中专属文章正文）
- 首页卡片、归档页、OG 分享卡的 summary 展示

### 移动端硬要求（照 AGENTS.md 执行）

各套主题的登录框、会员中心卡、付费墙遮挡层均需适配：390px 宽度验证、输入控件聚焦字号 ≥16px、底部元素处理 safe-area。
